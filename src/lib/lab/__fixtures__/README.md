# Synthetic lab fixtures

**These PDFs are synthetic and hand-built. They contain no real person's data.**

Every document in this directory is generated by `scripts/make-lab-fixtures.mjs`, which writes
uncompressed content streams by hand — base Helvetica, raw text-positioning operators, no PDF
library and no new dependency:

```
node scripts/make-lab-fixtures.mjs
```

The numbers in them are round and obviously fake (`12.1`, `4.0 - 12.0`, `Sigma Total`, `Sample
Person`), and the identity fields are placeholders (`SSN: [SSN]`, `123 EXAMPLE ST`) whose only job is
to prove that an identity line is refused and never stored. Nothing here is derived from a real
report, and nothing real may ever be added.

They exist because the layout is the hard part of ingestion, and a fixture is the only way to pin a
geometry down in a test. Each one reproduces a shape the real documents print:

| File | What it reproduces |
| --- | --- |
| `trend-matrix.pdf` | Three date columns; a name that wraps (`Widget One`); a value printed **above** its own name line with the report's `High` marker on the interval line below it; a wrapped interval upper bound (`5 -` / `50 K/ul`); a wrapped unit (`M/` + `ul`); two analytes printing the same name with different intervals; one-sided intervals (`<100 mg/dL`); and the bounded and qualitative result forms (`<0.5`, `TRACE`, `>39`) |
| `single-date.pdf` | A one-column table with an explicitly printed `Report Date:` field |
| `order-form.pdf` | A `Profiles/Tests` list with no values and no intervals — an order, not a result — carrying the identity, address and phone shapes the pipeline must refuse |
| `scan-like.pdf` | A page with no text layer at all, to prove the "looks like a scan" warning is raised instead of silently returning no rows |

Their exact expected observation sets are asserted in `src/lib/lab/extract/extract.test.ts`. If a
fixture changes, that test must change with it — deliberately, not by pasting new output over the old
expectations.
